# OpenTechIL Homebrew tap

Homebrew formulas for [agentry](https://github.com/OpenTechIL/agentry).

```sh
brew install OpenTechIL/tap/agy
```

`Formula/agy.rb` is generated automatically on every `agentry` release by the
`homebrew` job in [`release-binaries.yml`](https://github.com/OpenTechIL/agentry/blob/main/.github/workflows/release-binaries.yml)
— do not edit it by hand.
